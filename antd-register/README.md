# Replacement Register (antd-register)

Реестр замен компонентов на стандарте дизайна этого репозитория (Ant Design v6 + `@dynamics/ui-shared`).
Самостоятельное локальное приложение: браузерный клиент (`src/`) и сервер Replacement Register (`backend/app`).

## Запуск

Нужен Node.js 22 или новее. Из папки `design`:

```bash
npm install                 # один раз: зависимости всех приложений и сервера
npm run start:register      # сборка клиента и запуск → http://127.0.0.1:4182
```

Остановка — Ctrl+C. Повторный запуск без пересборки: `npm run serve -w antd-register`.

При первом запуске создаётся папка `antd-register/data` с тестовыми данными из `backend/seed`
(заказы 7226, 9312, 9318; данные вымышленные; 131 предложение, 59 записей базы замен, файлы обмена). Все изменения сохраняются в ней.
Чтобы вернуться к исходным тестовым данным, остановите приложение и удалите папку `data`.

Режим разработки (горячая перезагрузка клиента): в одном окне `npm run serve -w antd-register` (сервер API на 4181),
в другом `npm run dev:register` → http://localhost:5177.

## Состав

| Папка | Что это |
|---|---|
| `src/` | клиент: 11 разделов, модули обмена M01–M11, всплывающие карточки и формы |
| `serve.mjs` | запуск: сервер `backend/app` на порту 4181 + раздача `dist/` на 4182 с пересылкой `/api` |
| `backend/app` | сервер Replacement Register (API, хранение, фоновые задания, Excel/Word) из `old_apps/Replacement Register/app`, без старого браузерного клиента, тестов и QA-материалов |
| `backend/database` | SQL-схемы, которые сервер читает для проверки состояния |
| `backend/seed` | тестовые данные для первого запуска |
| `data/` | рабочие данные (создаётся при первом запуске, в git не попадает) |

Сервер работает в режиме локального просмотра (`RR_AUTH=preview`, хранение в файле): роль выбирается в меню
пользователя («Режим просмотра»). Загрузка внешних файлов показывает «антивирусная проверка недоступна» — антивирус в
локальном режиме не подключён (как и в исходном приложении).

**Данные вымышленные.** Встроенные данные сервера (`backend/app/data`) обезличены: изделия, децимальные номера,
поставщики, заказы, производственные заказы, коды 1С, документы и люди заменены вымышленными (например, «Gateway
Module GM-1», DSC.501010.101-03, «Delta Supply», «Orion Assembly»); связи между записями сохранены. `backend/seed`
создан заново прохождением всего цикла M01–M11 на этих данных. Изменения исходного кода сервера (все помечены
комментарием «antd-register»):

- `auth.js`: `crypto.argon2` (только пароли именованных учётных записей) берётся необязательно — сервер запускается на Node.js 22;
- `import-source.js`, `original-bom-inspection.js`: децимальный номер в имени файла распознаётся с любым буквенным префиксом;
- `assets/Card_of_Deviation_Template_v6.docx`: в шаблоне карты отступления фамилии заменены нейтральными;
  `server.js`: ожидаемая контрольная сумма шаблона обновлена.
